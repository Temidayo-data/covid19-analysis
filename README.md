# covid19-analysis
COVID-19 data analysis using Python (Biostatistics &amp; Public Health Perspective)
## Research Relevance

This project demonstrates the application of statistical analysis to real-world health data, providing insights relevant to public health and epidemiological research.


## Key Insights

# The United States and India exhibit significantly higher COVID-19 case trajectories compared to Nigeria, indicating differences in transmission dynamics and reporting systems.
# The analysis reveals periods of rapid exponential growth across all countries, consistent with pandemic wave patterns.
# Variations in case fatality rates suggest differences in healthcare capacity, testing strategies, and population-level factors.
